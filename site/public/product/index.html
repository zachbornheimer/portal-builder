The wizard, then the packet

Staff walk four gates. Applicants fill one page. Nothing in between is a dashboard leftover.

The wizard

A portal is built in WordPress. The authoring path is a four-step wizard — the same gates every time:

  • Start — name the opportunity, pick a template or a blank portal.
  • Build form — add fields, groups, and branches. Human labels lead; field ids stay a muted caption.
  • Map dests — bind each field to a Google Sheet header and a Drive folder the host already owns.
  • Publish — deadline, timezone, open or closed. Share the public URL.

Gate-seal state is never color alone: a hollow ring or a sealed disc, plus a name a screen reader can speak.

The public form

Applicants open a URL and meet a packet on paper. The title is Fraunces. The page is one form, one submit — not a multi-step account flow.

  • Staged files upload before submit, so a large score does not vanish on a timeout.
  • Anonymize can strip identity from judge-facing copies after staging.
  • A receipt goes out with an application id. The applicant knows the packet landed.

There is no applicant account, and no checkout. If the call names a fee, that line is copy — not a card form.
