Subprocessors

Who can see data

This is a processor list, not a signed DPA. We are not your counsel. If you need one, hire counsel.

Google (customer project)

When a host runs the plugin, application files and rows go to that host’s Google Drive and Sheets, under OAuth scopes they approve. DragonGate does not operate that Google project and does not take a second copy of the packet.

WordPress host

The host’s WordPress — and whoever hosts that WordPress — sees public form traffic and whatever WordPress stores (portal definitions, settings). Application packets are not kept as a WordPress inbox.

All Intersections

The plugin About screen links to allintersections.com for documentation. Application packets are not sent there.

This website

The marketing site and waitlist run on Cloudflare. Waitlist email is stored in Cloudflare KV so we can send launch notes. See the privacy note.
