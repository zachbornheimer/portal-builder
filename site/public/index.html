WordPress plugin

DragonGate Portals

The door that opens for the right applicant.

A WordPress plugin for application and intake portals — festivals, conservatories, and calls for scores. Staff build a form, map destinations, and publish. Applicants meet a paper packet. Files land in the host’s Google Drive; a row lands in Sheets.

How it works

Build, map, publish, receive.

01

Build

Start from a template or a blank portal. Add the fields the call actually needs — text, files, groups, branches.

02

Map

Point each field at a Sheet header and a Drive folder. Destinations stay on the host’s Google, not ours.

03

Publish

Set the deadline, open the gate, share the URL. Preview stays honest when the call is closed.

04

Receive

Applicants submit a packet. Files go to Drive. A row goes to Sheets. They get a receipt.

In the box

What the plugin actually does

Google Drive & Sheets

Uploads land in the host’s Drive. Metadata writes to the host’s Sheet. DragonGate does not keep a second copy of the packet.

Anonymize staged files

Judge-facing PDFs and recordings can have identity stripped before they leave the gate. Fail-open if the anonymizer is down.

Receipts

Every successful submit emails a receipt with an application id. The applicant knows it landed.

Dest-header mapping

Human labels lead in the form. Sheet column headers are mapped in the wizard — not guessed from field ids.

A paper packet

The public form is Fraunces on parchment, not a settings table. One page. One submit.

No Stripe

Fees can be mentioned in copy. There is no checkout, no card form, no payment processor in the plugin.

Who it’s for

Festivals, societies, conservatories

Calls for scores

One original work. Score PDF, recording, composer notes. A prize committee should be proud to open this packet.

Festival intake

Volunteer staff, a deadline, a Drive folder that already exists. The wizard is four gates — start, build, map, publish.

Conservatory applications

Serious materials, named reviewers, receipts. Identity can stay off the judge-facing files.
