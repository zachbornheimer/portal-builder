Features

Drive, Sheets, and an honest receipt

The plugin writes to the host’s Google. It does not invent a second filing cabinet, and it does not take cards.

Google Drive

Uploaded scores, recordings, and supporting files land in Drive folders the host maps. Backup is the host’s Drive, not a DragonGate bucket.

Google Sheets

Each submit appends a row. Reviewers already live in Sheets; they do not need a new admin to see who applied.

Dest-header mapping

The wizard maps each form field to a Sheet column header and a Drive destination. Headers are chosen, not inferred from internal ids.

Anonymize

When a portal asks for it, staged files go through an anonymizer before the judge-facing copy is stored. A failed call fail-opens — the original file is kept.

Receipts

Success emails a receipt: application id, what was sent, what happens next. The URL on that mail does not carry the applicant’s email.

No Stripe

DragonGate Portals is not a payments product. Application fees may appear as a line of copy. There is no checkout and no card data.
