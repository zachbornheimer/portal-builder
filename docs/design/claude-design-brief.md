## Design system — ground truth (do not invent a new palette)

Product: DragonGate Portals — WordPress plugin for application / intake portals (festivals, conservatories, calls for scores). Tagline: “The door that opens for the right applicant.”

Tokens (already shipped):
- Ink `#12140f` / `#1c1f17` / `#454a3c` / `#6e7460`
- Paper `#f7f4ec` / `#fcfbf6` / `#efebdd`
- Ember (only chromatic accent) `#b8501f` / `#963f16` / `#f4e2d4`
- Ember flow `linear-gradient(115deg, #c96a2e 0%, #b8501f 45%, #8b3a1a 100%)`
- Brass `#9c7a3c` / `#e4d9be`
- Success `#3f8a5c` · Error `#b8341f`
- Display: Fraunces. UI: Inter. Mono: IBM Plex Mono.
- 4px spacing scale. Radius 3 / 6 / 10 / pill.
- Wordmark: DragonGate Portals + the existing `icon.svg` seal (do not replace with a generic dragon or ISJAC mark).
- Feel: paper packet, not a SaaS dashboard. Host-agnostic — no ISJAC-only leftover copy.

## Project — pages
Home, Product, Features, Hosts, About, Waitlist, Terms, Privacy, Subprocessors.

Story: staff build a form, map Google Drive + Sheets, publish a URL. Applicants meet one paper packet, one submit. Files go to the host’s Drive; a row goes to Sheets. Receipt goes to the applicant. No WordPress applications inbox. Fee is informational (not charged in-product). Update path is WordPress Plugins → Upload Plugin ZIP.

One direction. Do not generate multiple polished alternatives.
